# 论文代码与补充实验统一入口

对应论文：《融合人工与机器学习特征的锂电池健康状态估计方法研究》。

## 版本与结果的使用

- `archive/submission/`：送审代码、笔记本和H5权重的部分只读副本（不包含旧版数据和结果）；`source_manifest.json`保存原路径、文件大小与SHA-256。与`long/3`对应代码及主预测一致，不把目录日期等同于新的实验版本。
- `src/`、`run.py`：修正版数据处理与训练。原模型的结构保持为参照，修正集合、筛选、变换及共同输入条件；其结果不能与旧结果混为同一次实验。
- `data/`：经哈希确认的处理数据。没有原始时间戳，不能由151列推断原始采样时刻。
- `results/`：每次训练的检查点、训练日志、变换器、划分、逐样本预测及结果。最后写入的`result.json`为完成标志，不能仅凭文件夹存在判定完成。
- `literature_results/`：依据公开描述构建的文献框架对照，不冒充文献原实现的严格复现。
- `reports/`、`figures/`：统一汇总、验收、论文替换文本和图表。

## 环境与运行

当前环境：Python 3.12、PyTorch 2.6.0+cu124、RTX 3080；完整版本见`requirements.lock.txt`，CUDA版PyTorch从官方cu124索引安装。仓库不包含虚拟环境；请先创建 Python 3.12 虚拟环境并按版本清单安装依赖。`prepare.py`仅用于在原工作区重建送审快照，独立检出时不需要运行。

```powershell
.\.venv\Scripts\python.exe validate.py
.\.venv\Scripts\python.exe run.py --suite all
.\.venv\Scripts\python.exe analyze.py --task summary
.\.venv\Scripts\python.exe analyze.py --task robustness
.\.venv\Scripts\python.exe analyze.py --task importance
.\.venv\Scripts\python.exe literature.py --reference all
.\.venv\Scripts\python.exe predict.py --run holdout__fair__joint__RE__Early__s2025 --device cuda --output reports/reinference_RE_Early.csv
```

从其他工作目录运行时，为脚本补充绝对路径即可；数据及输出路径相对代码根目录定位。`run.py --plan --suite all`只列出任务，不训练。

`predict.py`独立加载已保存模型及变换器，只对其记录的测试电池推理，并把输出写为新衍生文件；禁止覆盖已接受结果。完整电池清单见`reports/battery_split_manifest.csv`，最终指标见`reports/summary.csv`，图表位于`figures`，最终文字见`reports/论文替换文本与图表.md`。

## 已锁定协议

1. 原固定留出：39／13／14个完整电池标识，13,762／4,448／4,040条循环；传统模型不再将验证组合并训练。
2. 各训练集合独立筛选三个统计特征，使用训练内Pearson、Spearman绝对相关系数归一化求和；候选来自第1—149号点，方差ddof=0，偏度和超额峰度采用无偏估计。阶段序列仍保留151点。
3. 所有Scaler仅拟合训练组。公平输入提供温度及物理单位充电倍率，删除恒定放电倍率；保留原输入可用性的单种子修正对照另列为`legacy`，不称为旧实验精确重现。
   训练内方差为零的工况列在训练、验证和测试中均置零，避免未见值激活没有训练过的随机权重。该决定仅使用训练方差。第一版跨工况历史结果未纳入此仓库，不进入最终汇总；不受该修正影响的固定留出和交叉验证保留原检查点，并提供变换等价记录。
   V3修正了卷积输入的静态量接入：原CNN尾部2项工况及早期融合尾部静态量会被步长和池化丢弃。新公平CNN将两项工况移到时序编码后接入回归头，早期融合将静态量前置到卷积真正读取的位置。225项受影响实验重跑，V2旧结果未纳入此仓库。梯度路径测试确认新输入有效，历史模式仍可复现旧问题。中期、晚期、传统模型及仅曲线CNN的计算图未变，等价检查后复用原权重。
4. 固定留出、跨温度及跨倍率任务使用2025—2029五个种子；5折分组验证使用固定训练种子2025，单独报告折间波动，避免把折间差异混称为五次训练标准差。
5. 新神经网络训练最多200轮，训练批量512，Adam学习率0.001，验证早停25轮；使用训练标签均值初始化最终输出偏置，其他线性／卷积权重采用Glorot初始化。它们是公开记录的新训练设置。
6. 使用固定批量CUDA Graph降低启动开销，末批通过掩码保持真实样本MSE；预热后恢复权重并清零优化器状态，再进入正式epoch。Dropout及共同损失按原结构训练。
7. 晚期融合保留端到端联合训练；不新增门控、独立基学习器监督或OOF元学习器。只有文献框架对照中的堆叠模型使用分组OOF。
8. 初始网络及传统模型配置固定，验证集仅用于神经网络早停；本轮未通过测试集反向搜索参数，也未声称完成最优超参数搜索。

## 复现性与限制

- `validate.py`读取保存H5权重，采用独立NumPy前向计算核对PyTorch转换模型，覆盖三阶段四类结构；这不是调用TensorFlow运行时的逐位验证。
- CUDA设备在任务启动时必须可用；不会静默切换CPU后继续声称GPU实验。
- `result.json`保存代码哈希；训练代码变化后禁止沿用同名完成结果，应另建版本输出或保留原结果后重跑。
- 主结果同时保留逐电池和逐样本误差。样本总体均值与电池平均指标分别计算，不混用权重。
- 噪声为训练原信号标准差的0／0.5／1／2%，测试时在物理值上添加；人工特征从扰动后序列重新计算。相同阶段和噪声等级的各模型共享噪声样本。
- 排列重要性在相同温度、倍率内整分支置换，不打乱单条曲线内部顺序，不作因果解释。
- 受控缺点与插值仅为现有151点表示的敏感性试验，不能证明原始变长曲线的填充或重采样规则。
- 文献[15]、[55]、[61]的全文／代码细节不完整，所有局部实现选择和资源近似均在结果JSON和文献对照说明中列出。
- CPU完整预测耗时不含原始信号采集、文件读取和等待弛豫完成的时间；RSS为进程采样值，另列框架及数据基线；GPU内存为PyTorch分配器记录，不等于整卡总占用。
